# Minesweeper

A 9x7 board with 10 mines, designed for the badge's 160x120 logical screen.

<p><img src="images/minesweeper.png" width="480" alt="Minesweeper gameplay with beveled tiles, colored numbers, a flag counter, and a yellow cursor"></p>

## Install

Double-tap RESET, then run:

```sh
uv run --no-project tools/badge.py deploy --app minesweeper
diskutil eject /Volumes/BADGER
```

Tap RESET and select `minesweeper` in the launcher. Use your operating system's
eject command on Linux or Windows.

## Controls and rules

| Button | Action |
| --- | --- |
| A | Move left on release |
| C | Move right |
| Up/Down | Move vertically |
| B | Reveal the selected cell |
| Hold A, then B | Toggle a flag without moving the cursor |
| A+C | Start a fresh game |
| Rear HOME | Exit to the launcher |

The first reveal and every cell touching it are safe. Empty areas open
automatically. A number counts mines in the eight surrounding cells. Reveal
all 53 non-mine cells to win; flags alone do not win the game.

Press B on an open number to reveal its unflagged neighbors when the number of
surrounding flags matches. An incorrect flag can cause a loss. After a loss,
all mines appear. After either result, use A+C for a new board.

The header counter shows the remaining unplaced flags, clamped to zero.
Games are not saved across exit or reset.

## Art and clipping fix

The original layout put a 13-pixel system font into 11-pixel cells. The current
version uses original 3x5 pixel lettering, colored-number tiles, flag and mine
sprites, beveled hidden cells, and a yellow selection outline. The board
occupies x=8–150 and y=21–103; hints occupy y=107–112. No text depends on the
system font's baseline or height.

The PNG assets and icon are original artwork generated by
`tools/build_minesweeper_assets.py`. The documentation image is a deterministic
host-rendered gameplay preview using those exact assets, not a device photo.

```sh
uv run --no-project --with pillow tools/build_minesweeper_assets.py
uv run --no-project tools/test_minesweeper.py
uv run --no-project --with pillow tools/test_minesweeper_render.py
```

The render check covers every cursor cell, win/loss states, and all drawing
bounds. It also verifies that A+B flags the selected cell without moving it.
The installed version passed 189 cursor/state renders using Badgeware on the
physical badge. To repeat that check, run
`uvx --from mpremote==1.29.0 mpremote run tools/check_minesweeper_device.py`.
